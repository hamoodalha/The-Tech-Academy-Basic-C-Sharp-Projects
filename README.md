# C# Projects Portfolio
This repository contains projects completed during software development training using C#, .NET Framework, ASP.NET MVC, and Entity Framework.
## Projects
### Car Insurance
The Car Insurance project is an ASP.NET MVC web application that simulates a real car insurance website. Users enter personal and vehicle information to receive an insurance quote based on business logic.
#### Features
- Insurance quote calculation
- Customer information form
- Business logic implementation
- Admin page to view insurance quotes
- Database integration using Entity Framework

- Entity Framework
- SQL Server
